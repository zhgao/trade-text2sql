贸易金融 · Text-to-SQL

把贸易问题变成答案。

TradeQuery 让银行从业者用中文查询贸易全链路——信用证、货物动态、单据、付款，无需会写 SQL。每条查询都经过银行级护栏校验，并写入完整审计日志。

💬

自然语言 → SQL

像跟同事说话一样提问。Agent 会把问题关联到正确的表，借助专为贸易金融调优的示例写出正确的 SQL。

🛡️

银行级护栏

每条生成的 SQL 都要过五道确定性检查——单语句、只读、白名单表、禁用关键字、行数限制。数据库本身以只读方式打开。

🔧

查询自修复

如果 SQL 执行失败或结果可疑，Agent 会读懂报错、修正 SQL 并重试——最多两次，绝不轻易放弃。

📋

完整审计链

每个问题、每条生成的 SQL、返回行数和耗时都会写入审计日志。监管要的纸面留痕，我们天生就有。

工作原理

一个问题经过五个阶段，才变成你看到的答案。

1

意图理解

判断你在问什么——是业务查询还是闲聊。

2

表关联

从账本里挑出相关的表和列。

3

SQL 生成

写一条对应方言的 SELECT 语句。

4

护栏校验

校验：只读、白名单、行数限制。

5

生成回答

执行并用中文总结结果。

数据覆盖

一套虚构但自洽的亚洲贸易账本——结构与真实银行账本一致。
