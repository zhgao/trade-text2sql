Trade finance · Text-to-SQL

Turn trade questions into answers.

TradeQuery lets bankers query the full trade lifecycle — letters of credit, cargo movements, documents and payments — in plain English. No SQL required. Every query is validated by bank-grade guardrails and written to a full audit trail.

💬

Natural Language → SQL

Ask the way you'd ask a colleague. The agent links your question to the right tables and writes correct SQL, guided by few-shot examples tuned for trade finance.

🛡️

Bank-Grade Guardrails

Every generated query passes five deterministic checks — single statement, SELECT-only, table whitelist, banned keywords, row limits. The database itself opens read-only.

🔧

Self-Repairing Queries

If a query fails or returns nothing useful, the agent reads the error message, fixes the SQL and retries — up to two attempts — before ever giving up.

📋

Full Audit Trail

Every question, every generated SQL statement, row count and timing is written to an audit log. Regulators love paper trails. So do we.
