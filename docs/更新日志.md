# 更新日志

## v1.2.0（2026-10-14）
- Schema 预检索（RAG-for-Text2SQL）：表多时先检索候选表再让 LLM 精选，两阶段召回
  - `SCHEMA_RETRIEVAL=auto|tfidf|embedding|off`，默认 auto（12 张表以内不预筛，行为与旧版一致）
  - tfidf 后端零依赖、纯离线；embedding 后端走 OpenAI 兼容 `/embeddings` 接口，表向量本地缓存
  - `TABLE_KEYWORDS_CN`：每表一行中文业务关键词，加表时同步加
  - 16 个新测试，全量 56 测试通过

## v1.1.0（2026-10-14）
- 多数据库：SQLite / PostgreSQL / MySQL，`DATABASE_URL` 一行切换（SQLAlchemy 2.0）
- 中文版：`APP_LANG=zh` 一键切换中文界面 + 中文问答
- 新增中文部署文档、二开指南
