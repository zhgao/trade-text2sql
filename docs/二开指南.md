# TradeQuery 二开指南

> 面向买了源码、想换成自己业务的开发者。改完跑 `pytest backend/tests/` 确认没改坏。

## 一、换成你自己的数据库

1. `.env` 里改 `DATABASE_URL`：
   - SQLite（默认）：`sqlite:///./backend/db/trade.db`
   - PostgreSQL：`postgresql://user:pass@host:5432/dbname`
   - MySQL：`mysql+pymysql://user:pass@host:3306/dbname`
2. 删掉旧的 trade.db（SQLite），重启服务自动按新库建表。
3. **pg/mysql 账号必须只授 SELECT 权限**（生产安全要求）：
   ```sql
   -- PostgreSQL 示例
   GRANT CONNECT ON DATABASE trade TO trade_reader;
   GRANT USAGE ON SCHEMA public TO trade_reader;
   GRANT SELECT ON ALL TABLES IN SCHEMA public TO trade_reader;
   ```

## 二、换你自己的业务表（核心二开）

1. `backend/db/models.py`：按你的表结构改 SQLAlchemy 模型（表名、列名、类型）。
2. `backend/db/seed_data.py`：换成你的种子数据（或删空，生产环境不需要）。
3. `backend/agent/schema_catalog.py`：**最关键的一步**——给每个表/列写中文注释（模型靠注释理解业务），并更新 `FEW_SHOTS` / `FEW_SHOTS_ZH` 里的示例问题（换成你的业务问法，SQL 照写）。
4. 状态值如果是中文原文（如'逾期'），注释里写中英对照，prompt 规则里已有说明。

## 三、换大模型

`.env` 改 `LLM_MODEL`（如 `gpt-4o-mini`、`qwen-max`），`LLM_BASE_URL` 改对应地址。只要是 OpenAI 兼容接口就行。

## 四、改界面文案

- 中文版：`frontend/index.zh.html`
- 英文版：`frontend/index.html`
- 纯静态，改文字直接生效（Ctrl+F 搜关键词）。

## 五、改 Agent 行为

- prompt 规则：`backend/agent/graph.py`（`n_sql_gen` 的 Rules、few-shot 引用）
- 护栏：`backend/agent/guardrail.py`（白名单表、LIMIT 上限、黑名单关键字）
- 语言：`APP_LANG=en|zh`

## 六、常见二开需求工作量参考

| 需求 | 工作量 |
|---|---|
| 换表+改注释+示例 | 半天 |
| 加一张新表 | 1 小时（models+注释+seed） |
| 接企业微信/钉钉机器人 | 半天（调 /api/chat） |
| 加登录/权限 | 1–2 天 |
